# Перевод новостей

GoNews ориентирован на русскоязычную аудиторию: материалы англоязычных
источников автоматически переводятся на русский, а клиент всегда получает
контент на запрошенном языке (или оригинал, пока перевод не готов).

---

## 1. Принципы

1. **Русский по умолчанию.** `GONEWS_TRANSLATE_TARGETS=ru`, `lang=ru` —
   значение по умолчанию для API.
2. **Оригинал не теряется.** В БД хранятся и оригинал, и перевод.
3. **Перевод асинхронный.** Сбор новостей не ждёт перевода.
4. **Очередь durable.** Задачи переживают перезапуск процесса.
5. **Fallback.** Если один провайдер недоступен, используется следующий.
6. **Graceful degradation.** Пока перевода нет, API отдаёт оригинал со
   статусом `pending`.

---

## 2. Определение языка

`internal/langdetect` нормализует коды (`ru-RU` → `ru`, `en_US` → `en`) и
определяет язык по эвристикам:

- доля кириллицы → `ru`;
- доля латиницы → `en`;
- для источников язык часто известен из каталога (`SourceDef.Lang`).

Если язык источника совпадает с целевым, задача перевода не создаётся,
а `translation.status` равен `original`.

---

## 3. Провайдеры

Порядок задаётся `GONEWS_TRANSLATE_PROVIDERS`:

```
google,lingva,mymemory,libretranslate
```

| Провайдер | Endpoint | Лимит символов | Ключ | Особенности |
|---|---|---|---|---|
| `google` | `clients5.google.com/translate_a/t` | 4000 | нет | Основной; неофициальный endpoint, терпимее к автоматизации, чем `translate.googleapis.com` |
| `lingva` | `{LINGVA_URL}/api/v1/{src}/{dst}/{text}` | 1500 | нет | Open-source прокси Google; публичные инстансы часто отдают 429/503 |
| `mymemory` | `api.mymemory.translated.net/get` | 450 | нет | Бесплатный лимит, требует `langpair`, плохо работает с `auto` |
| `libretranslate` | `{LIBRETRANSLATE_URL}/translate` | 3500 | нет/опционально | Можно поднять свой сервер; рекомендуется для production |

Все провайдеры работают **без API-ключей**. Публичные инстансы
не гарантируют доступность и могут блокировать IP/дата-центры.

### 3.1 Fallback

`Translator.Translate` перебирает провайдеров по порядку:

1. Пропускает провайдеров в cooldown.
2. Делит текст на чанки по лимиту провайдера.
3. Переводит чанки последовательно.
4. При ошибке помечает провайдера и переходит к следующему.
5. Возвращает первый успешный результат и имя провайдера.

### 3.2 Circuit breaker

- Провайдер, вернувший ошибку, исключается на **2 минуты**.
- Успешный вызов снимает cooldown.
- Если все провайдеры в cooldown, предпринимается попытка с полным списком
  (лучше попробовать, чем не перевести вовсе).

### 3.3 Чанкинг

Текст режется на фрагменты не более лимита провайдера, по возможности:

1. по границе предложения (`.`, `!`, `?`, перевод строки);
2. иначе по пробелу или запятой;
3. в крайнем случае — жёстко по лимиту.

Фрагменты склеиваются через пробел. `GONEWS_TRANSLATE_MAX_CHARS` (4500)
ограничивает общий размер текста, отправляемого на перевод.

## 4. Очередь переводов

### 4.1 Создание задач

Задача `(article_id, target_lang)` создаётся:

- при вставке новой статьи с языком, отличным от целевого;
- при обновлении статьи, если перевода ещё нет;
- вручную через `POST /api/v1/admin/translate/backfill`.

Уникальный индекс `(article_id, target_lang)` защищает от дублей.
Если перевод уже существует, задача не создаётся.

### 4.2 Статусы

| Статус | Значение |
|---|---|
| `pending` | Ожидает обработки |
| `processing` | Захвачена воркером |
| `done` | Перевод сохранён |
| `failed` | Исчерпаны попытки |

При старте процесса `processing` сбрасывается в `pending` — задачи,
прерванные перезапуском, не теряются.

### 4.3 Воркеры

- Количество параллельных переводов — `GONEWS_TRANSLATE_WORKERS` (2).
- Цикл просыпается каждые **15 секунд** или по сигналу `Notify()` после
  сбора новостей.
- За один батч захватывается `workers × 2` задач.
- Внутри батча работает семафор на `workers` горутин.

### 4.4 Повторные попытки

`FailTranslationJob`:

- попытки 1–4 → `pending`, задержка `2^attempts` минут
  (2, 4, 8, 16 минут);
- попытка ≥ 5 → `failed`, следующая попытка через 24 часа
  (для ручного перезапуска/диагностики).

Задачи со статусом `failed` не выбираются автоматически. Чтобы повторить,
используйте backfill или сбросьте статус в БД:

```sql
UPDATE translation_jobs SET status='pending', attempts=0, next_attempt_at=datetime('now')
WHERE status='failed';
```

### 4.5 Что переводится

- `title` — обязательно;
- `summary` — обязательно;
- `content` — если отличается от summary.

Если перевод заголовка или описания не удался, статья не сохраняется как
переведённая: задача уходит на retry. Это гарантирует, что клиент не
получит частично переведённую карточку.

## 5. Статусы в API

`GET /api/v1/news?lang=ru` для каждой статьи возвращает:

```json
"translation": { "status": "ready", "provider": "google" }
```

| Статус | Условие |
|---|---|
| `original` | Язык статьи совпадает с запрошенным |
| `ready` | Есть запись в `article_translations` |
| `failed` | Есть задача со статусом `failed` |
| `pending` | Перевода ещё нет |

При `pending` поля `title`, `summary`, `content` содержат оригинальный
текст, а `originalLang` — исходный язык. Клиент может показать плашку
«Переводится…» и обновить карточку позже.

## 6. Конфигурация

```dotenv
GONEWS_TRANSLATE_ENABLED=true
GONEWS_TRANSLATE_PROVIDERS=google,lingva,mymemory,libretranslate
GONEWS_TRANSLATE_TARGETS=ru
GONEWS_TRANSLATE_WORKERS=2
GONEWS_TRANSLATE_TIMEOUT=12s
GONEWS_TRANSLATE_MAX_CHARS=4500
GONEWS_LINGVA_URL=https://lingva.ml
GONEWS_LIBRETRANSLATE_URL=https://libretranslate.com
```

Отключить перевод полностью:

```dotenv
GONEWS_TRANSLATE_ENABLED=false
```

Тогда англоязычные материалы отдаются как есть, а задачи не создаются.

## 7. Self-hosted LibreTranslate

Публичные инстансы часто недоступны. Для стабильной работы поднимите свой:

```bash
docker compose --profile translate up -d --build
```

Укажите:

```dotenv
GONEWS_LIBRETRANSLATE_URL=http://libretranslate:5000
GONEWS_TRANSLATE_PROVIDERS=libretranslate,google
```

Первый запуск скачивает языковые модели (`en`, `ru`) — это может занять
несколько минут и ~1 GB диска. Дальше перевод работает локально и не
зависит от внешних лимитов.

Проверка:

```bash
curl -X POST http://localhost:5000/translate \
  -H "Content-Type: application/json" \
  -d '{"q":"Hello world","source":"en","target":"ru","format":"text"}'
```

Ожидаемый ответ:

```json
{ "translatedText": "Привет, мир" }
```

> Для production рекомендуется именно этот вариант. Google/Lingva/MyMemory
> оставьте как fallback.

## 8. Мониторинг

`GET /api/v1/admin/translation-stats`:

```json
{ "data": { "pending": 74, "failed": 0, "done": 11 } }
```

Нормальная картина после сбора:

- `pending` временно растёт, затем снижается;
- `failed` близок к нулю;
- `done` монотонно растёт.

Тревожные сигналы:

- `failed` растёт — провайдеры блокируют или изменили API;
- `pending` не снижается — воркеры не успевают или все провайдеры в
  cooldown;
- `done` не растёт при большом `pending` — проверьте логи
  `translation provider failed`.

Ручной запуск:

```bash
curl -X POST http://localhost:8080/api/v1/admin/translate/backfill \
  -H "X-Admin-Token: $GONEWS_ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"lang":"ru","limit":500}'
```

## 9. Ограничения и правовые аспекты

- Публичные endpoints Google/Lingva/MyMemory не являются официальными
  API и могут измениться или заблокировать трафик.
- Лимиты и условия использования зависят от провайдера.
- Для коммерческого продукта используйте собственный LibreTranslate или
  официальный платный API.
- Перевод выполняется автоматически; не гарантируется идеальное качество.
- Не переводите персональные данные и закрытый контент через публичные
  сервисы.

## 10. Диагностика

| Симптом | Проверка | Решение |
|---|---|---|
| Все статьи `pending` | `translation-stats`, логи | Проверьте провайдеров, сеть, таймауты |
| `failed` быстро растёт | Логи `provider failed` | Смените порядок провайдеров, поднимите LibreTranslate |
| Google 429 | Логи | Добавьте fallback, снизьте `WORKERS`, используйте свой сервер |
| LibreTranslate 403 | `curl` к `/translate` | Публичный инстанс требует ключ — поднимите свой |
| Перевод обрезан | `MAX_CHARS`, лимит провайдера | Увеличьте лимит или уменьшите чанки |
| Долго | `WORKERS`, `TIMEOUT` | Увеличьте воркеры, проверьте сеть |
